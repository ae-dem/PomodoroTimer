# Помидорчатый таймер

**Демо:** [Открыть веб-приложение](https://ae-dem.github.io/PomodoroTimer/)

**Стек:** HTML5, CSS3, vanilla JavaScript.

---

## О приложении

Помидорчатый таймер - веб-приложение для тайм-менеджмента по методу Pomodoro. Метод помогает концентрироваться на задаче: вы работаете выбранный интервал, затем делаете короткий перерыв. После нескольких таких циклов - длинный перерыв. Так проще сохранять фокус и не выгорать.

Приложение подходит тем, кто хочет структурировать рабочий день, чередовать концентрацию и отдых и настраивать длительность сессий под себя.

---

## Что реализовано

- Таймер с циклами: работа → короткий перерыв → после N циклов длинный перерыв
- Настраиваемые интервалы (рабочее время, короткий и длинный перерыв, число циклов до длинного перерыва)
- Два модальных окна: информация о методе Pomodoro и настройки таймера
- Смена темы (светлая / тёмная)
- Пропуск текущего этапа 
- Звуковое уведомление при смене сессии
- Сохранение настроек в LocalStorage
- Адаптивная вёрстка, неоморфный (soft UI) стиль интерфейса

---

## Запуск локально

1. Клонировать репозиторий.
2. Открыть `index.html` в браузере или запустить через локальный сервер (например, Live Server в VS Code).
